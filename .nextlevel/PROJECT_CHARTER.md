# Project Charter: SiteScout AI

## 1. System Vision
SiteScout AI is an enterprise-grade local business discovery, digital presence audit, instant website generation, tokenized client preview/approval, and consultative sales outreach platform.

## 2. Core Value Streams
1. **Prospect Discovery**: Live geo-grounded lookup of local businesses with digital gaps (missing websites, incomplete Google profiles, absent 1-tap WhatsApp contact).
2. **Audit Engine**: Empirical presence and opportunity scoring (0-100) based on verified signals.
3. **Instant Website Studio**: 1:1 responsive static HTML generation with customization (colors, fonts, logos, section order, gallery, service pricing).
4. **Tokenized Client Portal**: Secure, PIN-optional client preview portal with inline feedback collection and 1-tap client approval.
5. **Sales & Outreach Suite**: Evidence-grounded sales copy and multi-channel outreach scripts without fabricated metrics.
6. **Production Deployment Engine**: Lifecycle state machine (`DRAFT` -> `PREVIEW_READY` -> `CLIENT_APPROVED` -> `DEPLOYING` -> `LIVE`) with static HTML export and custom domain mapping.
